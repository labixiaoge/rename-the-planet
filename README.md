One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters.

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Saturn is now The Pool Toy — the only planet light enough to float in a bathtub, and it still wears its inflatable ring everywhere.

Why it works: Saturn is the only planet less dense than water (it would float in a bathtub), and its rings double as the inflatable ring a pool toy wears. The name and the why land together as one joke, built on traits no other planet shares — not a pun on "Saturn".

## Run it

```sh
node main.ts
```

Deterministic, no network: it always writes the same 131-character line to `/output/entry.txt`.
